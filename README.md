# Calculadora de Intereses

> Calcula y compara interés simple y compuesto con una proyección visual del crecimiento.

[![React](https://img.shields.io/badge/React-19-61DAFB?logo=react&logoColor=white)](https://react.dev/) [![TypeScript](https://img.shields.io/badge/TypeScript-5-3178C6?logo=typescript&logoColor=white)](https://www.typescriptlang.org/) [![Vite](https://img.shields.io/badge/Vite-7-646CFF?logo=vite&logoColor=white)](https://vite.dev/)

## Características
- Comparación inmediata entre interés simple y compuesto.
- Frecuencia de composición configurable.
- Proyección anual con gráfico interactivo.
- Validación de montos, tasa y plazo.

## Tecnologías
React, TypeScript, Vite, Tailwind CSS, Recharts y Oxlint.

## Inicio rápido
```bash
npm install
npm run dev
```

## Scripts
| Comando | Descripción |
| --- | --- |
| `npm run dev` | Inicia el entorno de desarrollo. |
| `npm run build` | Genera la compilación de producción. |
| `npm run lint` | Ejecuta el análisis estático. |
| `npm run preview` | Sirve la compilación localmente. |
